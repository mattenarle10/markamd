# v1.7.10

v1.7.10 makes large Markdown previews more responsive and lets PDF exports use your selected font.

## fixed

- Reduce direction-handling overhead in large previews by avoiding redundant updates on LTR prose blocks. Mixed RTL/LTR text, explicit reading direction, code, and diagrams retain their direction handling (#195).
- Keep syntax-highlighted code monospace in PDF exports with every prose font.
- Wrap long URLs and filenames within printed pages.
- Keep simultaneous exports with identical filenames separate so one export cannot overwrite another.

## PDF fonts

- PDF exports now follow Settings > Reading > preview and print font: Inter, system, or mono (#196).
- Include the bundled Inter and JetBrains Mono fonts in print documents when needed, and wait for fonts to finish loading before opening the print dialog.
- Select mono to export headings, paragraphs, lists, and tables in monospace without installing an extra font.

## maintenance

- Updated the opener plugin to 2.7.2 in both Rust and JavaScript, the single-instance plugin to 2.5.5, and tauri-build to 2.7.4.

# v1.7.5

v1.7.5 fixes line breaks in table cells and refreshes diagram rendering and native plugins.

## fixed

- Rendered `<br>`, `<br/>`, and `<br />` as line breaks in table cells and paragraphs, matching GitHub preview (#155).
- Kept all other raw HTML escaped in the preview and PDF export.

## improved

- Updated mermaid to v12 with its refreshed default diagram look and layout.
- Updated the Tauri updater, file system, dialog, opener, and single-instance plugins.

## notes

- Mermaid 12 needs a Safari 17.4+ webview on macOS for diagrams to render.
- Signed updater artifacts remain enabled.

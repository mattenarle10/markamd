# v1.7.9

v1.7.9 restores unsaved drafts after a restart and updates the desktop dependencies with security fixes.

## fixed

- Restore local backups of unsaved file edits and untitled tabs, including the active draft, when the app restarts (#187).
- Clear draft backups when changes are saved or a tab is explicitly discarded. If the original file changed externally, keep the recovered edits and show a conflict warning.
- Keep recovered text available when its original file is missing, and warn if draft backup storage is full or unavailable.
- Preserve newer typing when an earlier save finishes, including when switching tabs during the save.

## security

- Updated rustls to 0.23.46 and the updater's zip dependency to 9.2.2 to address reported security vulnerabilities.

## maintenance

- Updated the updater plugin to 2.14.1, the filesystem plugin to 2.7.1, the dialog plugin to 2.8.4, and serde_json to 1.0.154.
- Aligned the frontend plugin packages with their Rust versions.

## notes

- Draft backups stay on your device. Use Save to write changes to the original file.
- Thanks to @Rinka-Sei for reporting the draft recovery request.
- Signed updater artifacts remain enabled.

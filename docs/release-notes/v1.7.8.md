# v1.7.8

v1.7.8 fixes the find shortcut on Windows and Linux and updates the desktop dependencies.

## fixed

- Reserved Ctrl+F for search on Windows and Linux. Fullscreen now uses F11, as documented; macOS keeps Ctrl+Cmd+F (#178).
- Updated the Help and command palette hints to show the correct fullscreen shortcut for each platform.
- Updated the updater plugin to 2.13.2, which preserves the existing macOS app when an update installation fails.

## maintenance

- Updated Tauri to 2.12.2, the filesystem plugin to 2.6.0, the single-instance plugin to 2.5.2, and the process plugin to 2.4.0.
- Aligned the frontend filesystem, process, and updater packages with their Rust plugin versions.
- Retained the rustls 0.23.45 security fix and signed updater artifacts.

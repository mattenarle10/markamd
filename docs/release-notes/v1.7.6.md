# v1.7.6

v1.7.6 adds a manual refresh for the explorer and updates the Tauri shell.

## added

- Added a refresh button to the explorer header, next to search and add folder, that re-reads the file tree from disk (#163).
- Added a "refresh explorer" command to the command palette.
- Kept expanded folders, active search results, and unsaved edits intact when refreshing.

## improved

- Updated Tauri to 2.12 and window-vibrancy to 0.8.1.

## notes

- Automatic folder monitoring is unchanged; the refresh button covers cases where an external change is missed.
- Signed updater artifacts remain enabled.
